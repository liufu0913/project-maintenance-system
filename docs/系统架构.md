## 技术栈

### 后端技术栈
- **框架**: Spring Boot 3.x + Spring Cloud
- **ORM**: MyBatis-Plus
- **数据库**: MySQL 8.0
- **缓存**: Redis
- **消息队列**: RabbitMQ (用于异步任务)
- **搜索**: Elasticsearch (可选，用于知识库检索)
- **文件存储**: MinIO / 本地文件系统
- **认证**: JWT + Spring Security
- **API文档**: Swagger/Springdoc-openapi
- **任务调度**: Quartz / Spring Scheduler

### 前端技术栈
- **框架**: Vue 3 + Vite
- **UI组件库**: Element Plus / Naive UI
- **状态管理**: Pinia
- **HTTP客户端**: Axios
- **文件上传**: Vue Upload
- **图表**: ECharts
- **富文本编辑**: WangEditor / Quill
- **PPT生成**: pptxgen-js

### 部署与运维
- **容器化**: Docker + Docker Compose
- **编排**: Kubernetes (可选)
- **CI/CD**: GitHub Actions / Jenkins
- **监控**: Prometheus + Grafana
- **日志**: ELK Stack

## 核心模块说明

### 1. 认证授权模块 (AuthService)
- 用户注册、登录、密码修改
- JWT令牌生成和验证
- 会话管理
- 权限控制

**数据隔离**: 无隔离（系统级别）

### 2. 项目安装管理模块 (ProjectService)
- 项目创建、更新、查询
- 安装工单管理
- 施工进度记录
- 项目资料归档

**数据隔离**: 无隔离（所有用户可见共享数据）

### 3. 售后维护管理模块 (MaintenanceService)
- 工单管理
- 故障记录和诊断
- 维修处理
- 客户回访
- 维护台账

**数据隔离**: 无隔离（所有用户可见共享数据）

### 4. 沟通协调管理模块 (CommunicationService)
- 沟通记录管理
- 对接事项跟踪
- 待办项管理
- 会议纪要

**数据隔离**: 无隔离（所有用户可见共享数据）

### 5. AI文档生成模块 (AiReportService)
- 日报自动生成
- 月报聚合生成
- 年报生成及PPT输出
- 故障心得生成
- 知识库管理和沉淀

**数据隔离**: **用户隔离** - 每个用户仅能查看自己的报告和内容

#### 5.1 日报生成流程
```
定时任务 (每天凌晨1:00)
    ↓
扫描当日有工作数据的用户
    ↓
聚合用户的工单、记录、待办数据
    ↓
调用AI服务生成日报内容
    ↓
存储到数据库 (daily_reports表，user_id字段)
    ↓
用户登录后可在个人工作台查看
```

#### 5.2 月报生成流程
```
定时任务 (每月1日凌晨2:00)
    ↓
扫描当月有工作数据的用户
    ↓
聚合用户的所有日报数据
    ↓
调用AI服务生成月报内容
    ↓
存储到数据库 (monthly_reports表，user_id字段)
```

#### 5.3 年报生成流程
```
定时任务 (每年1月1日凌晨4:00)
    ↓
扫描当年有工作数据的用户
    ↓
聚合用户的所有月报数据
    ↓
调用AI服务生成年报内容
    ↓
调用PPT生成服务 (pptxgen-js)
    ↓
存储报告和PPT文件
    ↓
用户可下载PPT文件
```

#### 5.4 知识库自动沉淀流程
```
定时任务 (每月1日凌晨3:00)
    ↓
扫描上月所有故障案例
    ↓
自动生成故障心得 (fault_summaries)
    ↓
聚合相似故障进行分类
    ↓
生成知识库文章 (knowledge_base)
    ↓
按分类、日期、标签组织
    ↓
每个用户可检索查阅（全量可见）
    ↓
用户可评价文章有用度
```

### 6. 统计分析模块 (StatisticsService)
- 项目统计
- 工单统计
- 故障统计
- 个人工作统计（用于AI报告）

**数据隔离**: 部分隔离（个人统计隔离，全局统计共享）

## 权限与数据隔离策略

### 业务数据权限 (共享可见)
- **项目管理**: 所有用户可查看全部项目和工单
- **售后维护**: 所有用户可查看全部故障和维修记录
- **沟通协调**: 所有用户可查看全部沟通记录和待办项
- **知识库**: 所有用户可查看全部知识库文章

### 个人数据权限 (隔离)
- **日报**: 用户仅能查看自己的日报
- **月报**: 用户仅能查看自己的月报
- **年报**: 用户仅能查看自己的年报
- **个人统计**: 用户仅能查看自己的工作统计

### 实现方式
```java
// 个人报告查询需要验证
@GetMapping("/daily-reports")
public Result getDailyReports(
    @RequestParam Long userId,
    HttpServletRequest request
) {
    Long currentUserId = SecurityUtils.getCurrentUserId(request);
    
    // 仅能查看自己的报告
    if (!userId.equals(currentUserId)) {
        throw new BusinessException("无权限查看他人报告");
    }
    
    return dailyReportService.list(userId);
}
```

## 数据安全与隐私保护

### 1. 认证安全
- 使用JWT令牌，有效期可配置
- 密码使用bcrypt加密
- 支持会话超时自动登出

### 2. 数据加密
- 敏感字段（密码、电话）数据库加密存储
- HTTPS传输层加密
- 文件上传使用加密存储

### 3. 日志审计
- 所有数据修改操作记录日志
- 记录操作人、操作时间、修改内容
- 支持操作日志查询和审计

### 4. 备份恢复
- 每日数据库自动备份
- 支持指定时间点恢复
- 文件定期备份到对象存储

## 性能优化策略

### 1. 缓存策略
- Redis缓存热门数据（用户信息、项目列表）
- 缓存失效策略：更新时主动清除
- 缓存穿透保护

### 2. 数据库优化
- 关键字段建立索引
- 分页查询避免全表扫描
- 复杂查询使用视图或存储过程

### 3. 接口优化
- 支持字段选择性返回
- 使用分页和懒加载
- 异步处理耗时操作

### 4. 文件处理
- 使用对象存储（MinIO）
- 文件压缩和格式转换
- CDN分发

## 监控与告警

### 1. 系统监控
- CPU、内存、磁盘使用率
- 数据库连接数、慢查询
- API响应时间

### 2. 业务监控
- 工单处理率
- 故障解决时间
- 客户满意度

### 3. 告警规则
- 系统可用性 < 99%
- API响应时间 > 1s
- 错误率 > 1%
- 磁盘空间不足
