**2. 项目管理Service**
```java
@Service
public class ProjectService {
    
    @Autowired
    private ProjectMapper projectMapper;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    // 创建项目
    public ProjectVO createProject(ProjectCreateDTO dto) {
        Project project = new Project();
        BeanUtils.copyProperties(dto, project);
        projectMapper.insert(project);
        
        // 更新缓存
        redisTemplate.opsForList()
            .leftPush("project:list", project);
        
        return ProjectConverter.toVO(project);
    }
    
    // 获取项目列表（全量共享）
    public PageResult<ProjectVO> getProjectList(int page, int pageSize) {
        IPage<Project> pageData = projectMapper.selectPage(
            new Page<>(page, pageSize),
            null
        );
        return PageResult.success(pageData);
    }
}
```

**3. 日报生成Service（用户隔离）**
```java
@Service
public class DailyReportService {
    
    @Autowired
    private DailyReportMapper reportMapper;
    
    @Autowired
    private AiReportGenerator aiGenerator;
    
    // 生成日报（用户隔离）
    public DailyReportVO generateDailyReport(Long userId, LocalDate reportDate) {
        // 验证权限：仅能为当前用户生成
        Long currentUserId = SecurityUtils.getCurrentUserId();
        if (!userId.equals(currentUserId)) {
            throw new BusinessException("无权限生成他人报告");
        }
        
        // 收集该用户的工作数据
        WorkData workData = collectUserWorkData(userId, reportDate);
        
        // 调用AI生成报告
        String aiGeneratedContent = aiGenerator.generateDailyReport(workData);
        
        // 保存到数据库
        DailyReport report = new DailyReport();
        report.setUserId(userId);
        report.setReportDate(reportDate);
        report.setWorkContent(aiGeneratedContent);
        report.setGenerationStatus("已生成");
        reportMapper.insert(report);
        
        return ReportConverter.toVO(report);
    }
    
    // 获取用户日报（用户隔离）
    public List<DailyReportVO> getUserDailyReports(Long userId) {
        // 验证权限：仅能查看自己的报告
        Long currentUserId = SecurityUtils.getCurrentUserId();
        if (!userId.equals(currentUserId)) {
            throw new BusinessException("无权限查看他人报告");
        }
        
        List<DailyReport> reports = reportMapper.selectByUserId(userId);
        return reports.stream()
            .map(ReportConverter::toVO)
            .collect(Collectors.toList());
    }
}
```

**2. Pinia状态管理**
```javascript
// stores/project.js
import { defineStore } from 'pinia'
import { getProjectList, createProject } from '@/api/project'

export const useProjectStore = defineStore('project', {
  state: () => ({
    projects: [],
    total: 0,
    loading: false
  }),
  
  actions: {
    async fetchProjects(page, pageSize) {
      this.loading = true
      try {
        const res = await getProjectList({ page, pageSize })
        this.projects = res.data.rows
        this.total = res.data.total
      } finally {
        this.loading = false
      }
    },
    
    async addProject(projectData) {
      const res = await createProject(projectData)
      this.projects.unshift(res.data)
      return res
    }
  }
})
```

### 六、代码规范

#### 6.1 命名规范
- 类名：大驼峰 (PascalCase)
- 方法名：小驼峰 (camelCase)
- 常量：全大写下划线分割 (CONSTANT_NAME)
- 数据库表名：小写下划线分割 (table_name)

#### 6.2 代码风格
- 使用Lombok减少冗余代码
- 使用日志而不是System.out.println
- 为公共方法添加Javadoc注释
- 控制单个方法行数 < 50行

#### 6.3 Git提交规范

```bash
# 提交消息格式

git commit -m "fix: 修复登录验证bug"
```

### 七、常见问题

#### Q1: 连接数据库失败
```
A: 检查MySQL是否启动，数据库名称、用户名、密码是否正确
   运行: mysql -u root -p -e "show databases;"
```

#### Q2: 依赖包下载失败
```
A: 修改Maven镜像源
   编辑: ~/.m2/settings.xml
   添加阿里云镜像
```

#### Q3: 前端调用API 404
```
A: 检查后端服务是否启动（http://localhost:8080）
   检查API路径是否正确
   检查CORS跨域配置
```

### 八、进阶开发

#### 8.1 实现自定义拦截器

```java
@Component
public class JwtInterceptor implements HandlerInterceptor {
    
    @Override
    public boolean preHandle(HttpServletRequest request, 
                            HttpServletResponse response, 
                            Object handler) throws Exception {
        String token = request.getHeader("Authorization");
        if (StringUtils.isEmpty(token)) {
            throw new UnAuthorizedException("未找到授权令牌");
        }
        
        if (!JwtUtil.validateToken(token)) {
            throw new UnAuthorizedException("令牌已过期");
        }
        
        Long userId = JwtUtil.getUserId(token);
        SecurityUtils.setCurrentUserId(userId);
        
        return true;
    }
}
```

#### 8.2 集成Elasticsearch

```java
@Configuration
public class ElasticsearchConfig {
    
    @Bean
    public RestHighLevelClient restHighLevelClient() {
        final CredentialsProvider credentialsProvider = 
            new BasicCredentialsProvider();
        credentialsProvider.setCredentials(
            AuthScope.ANY,
            new UsernamePasswordCredentials("user", "password")
        );
        
        RestClientBuilder builder = RestClient.builder(
            new HttpHost("localhost", 9200, "http"))
            .setHttpClientConfigCallback(
                httpClientBuilder -> 
                    httpClientBuilder.setDefaultCredentialsProvider(
                        credentialsProvider));
        
        return new RestHighLevelClient(builder);
    }
}
```
