# 项目运维管理系统 - 部署指南

## 一、部署前检查清单

- [ ] JDK 17+ 已安装
- [ ] Maven 3.9+ 已安装
- [ ] MySQL 8.0+ 已启动
- [ ] Redis 7.0+ 已启动
- [ ] Node.js 18+ 已安装
- [ ] 数据库初始化脚本已执行
- [ ] 环境变量已配置

## 二、后端部署

### 2.1 打包应用

```bash
cd backend

# 清理并构建
mvn clean package -DskipTests

# 输出文件位置: target/maintenance-system-1.0.0.jar
```

### 2.2 配置生产环境

创建 `application-prod.yml`:

```yaml
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  application:
    name: maintenance-system
  
  datasource:
    url: jdbc:mysql://db-server:3306/project_maintenance?useSSL=true&serverTimezone=UTC
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
    driver-class-name: com.mysql.cj.jdbc.Driver
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
      connection-timeout: 30000
  
  redis:
    host: ${REDIS_HOST}
    port: ${REDIS_PORT}
    password: ${REDIS_PASSWORD}
    timeout: 2000ms
    jedis:
      pool:
        max-active: 20
        max-idle: 10
  
  jpa:
    hibernate:
      ddl-auto: validate

# 日志配置
logging:
  level:
    root: INFO
    com.maintenance: DEBUG
  file:
    name: logs/application.log
    max-size: 100MB
    max-history: 30

# JWT配置
jwt:
  secret: ${JWT_SECRET}
  expiration: 86400000  # 24小时
```

### 2.3 启动后端服务

```bash
# 方式1: 直接运行JAR
java -Xmx1024m -Xms512m \
  -Dspring.profiles.active=prod \
  -Dspring.datasource.url="jdbc:mysql://localhost:3306/project_maintenance" \
  -Dspring.datasource.username="root" \
  -Dspring.datasource.password="password" \
  -jar maintenance-system-1.0.0.jar

# 方式2: 使用systemd服务
sudo tee /etc/systemd/system/maintenance-system.service > /dev/null <<EOF
[Unit]
Description=Project Maintenance System
After=network.target

[Service]
Type=simple
User=app
ExecStart=/usr/bin/java -Xmx1024m -Xms512m \
  -Dspring.profiles.active=prod \
  -jar /opt/maintenance-system-1.0.0.jar
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

# 启动服务
sudo systemctl start maintenance-system
sudo systemctl enable maintenance-system

# 查看状态
sudo systemctl status maintenance-system
```

## 三、前端部署

### 3.1 构建前端应用

```bash
cd frontend

# 安装依赖
npm install

# 生产构建
npm run build

# 输出目录: dist/
```

### 3.2 配置生产环境

创建 `.env.production`:

```env
VITE_API_BASE_URL=https://api.example.com
VITE_API_TIMEOUT=10000
VITE_APP_TITLE=项目运维管理系统
```

### 3.3 部署到Nginx

```nginx
# /etc/nginx/sites-available/maintenance-system
upstream backend {
    server localhost:8080;
}

server {
    listen 80;
    listen 443 ssl http2;
    server_name maintenance-system.example.com;

    # SSL证书配置
    ssl_certificate /etc/nginx/ssl/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/key.pem;

    # 前端静态资源
    location / {
        root /var/www/maintenance-system;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # API代理
    location /api {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
    }

    # 缓存配置
    location ~* \.(js|css|png|jpg|jpeg|gif|svg)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # 压缩配置
    gzip on;
    gzip_types text/plain text/css text/javascript 
               application/json application/javascript application/xml+rss;
    gzip_min_length 1000;
}
```

部署步骤：

```bash
# 创建部署目录
sudo mkdir -p /var/www/maintenance-system
sudo chown -R www-data:www-data /var/www/maintenance-system

# 复制前端文件
sudo cp -r dist/* /var/www/maintenance-system/

# 验证Nginx配置
sudo nginx -t

# 重启Nginx
sudo systemctl restart nginx
```

## 四、Docker容器化部署

### 4.1 后端Dockerfile

创建 `backend/Dockerfile`:

```dockerfile
FROM openjdk:17-slim

WORKDIR /app

# 复制JAR文件
COPY target/maintenance-system-1.0.0.jar app.jar

# 暴露端口
EXPOSE 8080

# 启动应用
ENTRYPOINT ["java", "-Xmx1024m", "-Xms512m", \
            "-Dspring.profiles.active=prod", \
            "-jar", "app.jar"]
```

### 4.2 前端Dockerfile

创建 `frontend/Dockerfile`:

```dockerfile
# 构建阶段
FROM node:18-alpine AS builder

WORKDIR /app

COPY package.json yarn.lock ./
RUN yarn install

COPY . .
RUN yarn build

# 运行阶段
FROM nginx:alpine

COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/nginx.conf

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

### 4.3 Docker Compose配置

创建 `docker-compose.yml`:

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: maintenance-mysql
    environment:
      MYSQL_ROOT_PASSWORD: root_password
      MYSQL_DATABASE: project_maintenance
    volumes:
      - mysql-data:/var/lib/mysql
      - ./database/init.sql:/docker-entrypoint-initdb.d/init.sql
    ports:
      - "3306:3306"
    networks:
      - maintenance-network

  redis:
    image: redis:7-alpine
    container_name: maintenance-redis
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data
    networks:
      - maintenance-network

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: maintenance-backend
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/project_maintenance
      SPRING_DATASOURCE_USERNAME: root
      SPRING_DATASOURCE_PASSWORD: root_password
      SPRING_REDIS_HOST: redis
      SPRING_REDIS_PORT: 6379
      JWT_SECRET: ${JWT_SECRET:-your-secret-key-here}
    ports:
      - "8080:8080"
    depends_on:
      - mysql
      - redis
    networks:
      - maintenance-network
    restart: unless-stopped

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: maintenance-frontend
    ports:
      - "80:80"
    depends_on:
      - backend
    networks:
      - maintenance-network
    restart: unless-stopped

volumes:
  mysql-data:
  redis-data:

networks:
  maintenance-network:
    driver: bridge
```

启动容器：

```bash
# 启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f backend

# 停止服务
docker-compose down

# 删除数据卷
docker-compose down -v
```

## 五、Kubernetes部署 (可选)

### 5.1 创建Deployment

创建 `k8s/backend-deployment.yaml`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: maintenance-backend
  labels:
    app: maintenance-backend
spec:
  replicas: 3
  selector:
    matchLabels:
      app: maintenance-backend
  template:
    metadata:
      labels:
        app: maintenance-backend
    spec:
      containers:
      - name: backend
        image: maintenance-system:backend-1.0.0
        ports:
        - containerPort: 8080
        env:
        - name: SPRING_DATASOURCE_URL
          valueFrom:
            configMapKeyRef:
              name: maintenance-config
              key: db-url
        - name: SPRING_REDIS_HOST
          valueFrom:
            configMapKeyRef:
              name: maintenance-config
              key: redis-host
        resources:
          requests:
            memory: "512Mi"
            cpu: "250m"
          limits:
            memory: "1024Mi"
            cpu: "500m"
        livenessProbe:
          httpGet:
            path: /api/health
            port: 8080
          initialDelaySeconds: 30
          periodSeconds: 10
```

### 5.2 创建Service

```yaml
apiVersion: v1
kind: Service
metadata:
  name: maintenance-backend-service
spec:
  selector:
    app: maintenance-backend
  ports:
  - protocol: TCP
    port: 8080
    targetPort: 8080
  type: LoadBalancer
```

## 七、性能优化

### 7.1 数据库优化

```sql
-- 创建索引加速查询
CREATE INDEX idx_project_status ON installation_projects(install_status);
CREATE INDEX idx_order_assign_user ON installation_orders(assign_user_id);
CREATE INDEX idx_report_user_date ON daily_reports(user_id, report_date);

-- 表分区（大数据量情况）
ALTER TABLE maintenance_orders
PARTITION BY RANGE (YEAR(created_at)) (
  PARTITION p2023 VALUES LESS THAN (2024),
  PARTITION p2024 VALUES LESS THAN (2025),
  PARTITION p2025 VALUES LESS THAN MAXVALUE
);
```

## 八、故障排查

### 常见问题

| 问题 | 解决方案 |
|------|--------|
| 数据库连接失败 | 检查MySQL服务状态、网络连通性、用户权限 |
| Redis连接失败 | 检查Redis服务状态、端口配置、密码设置 |
| 内存溢出 | 增加JVM堆内存: -Xmx2048m |
| API响应缓慢 | 检查数据库慢查询、缓存是否生效、连接池大小 |
| 前端页面加载失败 | 检查Nginx配置、后端API是否可访问 |

## 九、备份与恢复

### 9.1 数据库备份

```bash
# 完整备份
mysqldump -u root -p project_maintenance > backup-$(date +%Y%m%d-%H%M%S).sql

# 定时备份脚本
#!/bin/bash
BACKUP_DIR="/backups/mysql"
DATE=$(date +%Y%m%d-%H%M%S)
mysqldump -u root -p${MYSQL_PASSWORD} project_maintenance > ${BACKUP_DIR}/backup-${DATE}.sql
# 删除7天前的备份
find ${BACKUP_DIR} -mtime +7 -delete
```

## 十、升级与维护

### 10.1 版本升级

```bash
# 1. 拉取最新代码
git pull origin main

# 2. 备份数据库
mysqldump -u root -p project_maintenance > backup-before-upgrade.sql

# 3. 编译新版本
mvn clean package -DskipTests

# 4. 停止旧服务
systemctl stop maintenance-system

# 5. 替换JAR文件
cp target/maintenance-system-1.0.0.jar /opt/

# 6. 启动新服务
systemctl start maintenance-system

# 7. 验证升级
curl http://localhost:8080/api/health
```
