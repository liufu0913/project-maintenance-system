# 项目运维管理系统 - 数据库设计文档

## 一、系统概述

项目运维管理系统采用**SQL关系型数据库架构**，包含用户管理、项目安装、售后维护、沟通协调和AI文档生成等核心模块。

---

## 二、核心数据表设计

### 1. **用户账号体系** 

#### 表1.1: users（用户表）
```
字段名              数据类型        说明                约束
user_id             BIGINT         用户唯一标识         PRIMARY KEY, AUTO_INCREMENT
username            VARCHAR(50)    用户名               UNIQUE, NOT NULL
email               VARCHAR(100)   邮箱                 UNIQUE, NOT NULL
password_hash       VARCHAR(255)   密码哈希值           NOT NULL
phone               VARCHAR(20)    电话号码             UNIQUE
real_name           VARCHAR(50)    真实姓名             
department          VARCHAR(100)   部门                 
position            VARCHAR(50)    职位                 
avatar_url          VARCHAR(255)   头像URL              
status              TINYINT        账户状态(0禁用,1正常) DEFAULT 1
created_at          DATETIME       创建时间             DEFAULT CURRENT_TIMESTAMP
updated_at          DATETIME       更新时间             ON UPDATE CURRENT_TIMESTAMP
```

#### 表1.2: user_sessions（用户会话表）
```
字段名              数据类型        说明                约束
session_id          VARCHAR(255)   会话ID              PRIMARY KEY
user_id             BIGINT         用户ID              FOREIGN KEY -> users.user_id
token               VARCHAR(500)   JWT令牌             UNIQUE
login_time          DATETIME       登录时间            DEFAULT CURRENT_TIMESTAMP
expiry_time         DATETIME       过期时间            NOT NULL
ip_address          VARCHAR(50)    登录IP              
user_agent          VARCHAR(255)   用户代理信息         
status              TINYINT        会话状态(0已过期,1活跃) DEFAULT 1
```

## 四、关键业务流程

### 1. **项目全生命周期**
```
installation_projects (创建) 
    → installation_progress (跟踪进度)
    → installation_orders (分配工单)
    → installation_records (记录施工)
    → installation_documents (归档资料)
    → maintenance_orders (切换到维护阶段)
```

### 2. **故障处理闭环**
```
maintenance_orders (报障)
    → fault_records (诊断)
    → repair_records (维修)
    → maintenance_followup (回访)
    → fault_summaries (AI生成心得)
    → knowledge_base (知识库沉淀)
```

### 3. **AI文档生成流程**
```
业务数据 (日报、月报基础数据)
    → daily_reports (AI自动生成)
    → monthly_reports (AI聚合)
    → annual_reports (AI合成 + PPT生成)

故障数据
    → fault_records + repair_records
    → fault_summaries (AI自动生成心得)
    → knowledge_base (每月自动汇总)
```

## 五、数据隔离设计

### 用户数据隔离策略
- **行级隔离**：所有业务表均通过 `user_id` 或 `created_by` 关联用户
- **查询权限**：应用层应使用当前登录用户ID作为WHERE条件筛选数据
- **示例**：
  ```sql
  SELECT * FROM daily_reports WHERE user_id = #{currentUserId};
  SELECT * FROM installation_orders WHERE assign_user_id = #{currentUserId};
  ```
